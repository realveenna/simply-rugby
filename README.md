# Simply Rugby

A full-stack rugby club management system designed to manage players, teams, training, matches, injuries and club administration.

## Overview

Simply Rugby is a database-driven web application developed using PHP, Object-Oriented Programming and MySQL. The system provides different functionality and permissions for administrators, coaches, players and parents, allowing rugby clubs to manage day-to-day operations through a centralised platform.

## Features

### 🔐 Authentication & Role-Based Access

* Secure user authentication
* Role-based access control
* Dedicated functionality for administrators, coaches, players and parents
* Different permissions based on user roles
* Protected access to role-specific features

### 👨‍👩‍👧 Parent & Player Management

* Parent dashboard
* Player dashboard
* Player profiles
* Player reports
* Player information management
* Parent access to relevant player information

### 🏉 Team & Squad Management

* Manage rugby squads and teams
* Organise players within teams
* Manage player information and team membership

### 📅 Training Management

* Create and manage training sessions
* Schedule training activities
* Manage training information
* Track relevant player participation

### 🩹 Injury Management

* Record player injuries
* Manage injury information
* Monitor player injury records
* Associate injuries with individual players

### 🏆 Match Management

* Create and manage matches
* Manage match information
* Track match-related data
* Associate players and teams with matches

### 📊 Player Reports

* Generate and view player reports
* Manage player performance-related information
* Present player information in an organised format

### 🛡️ Data Protection

* Role-based access to sensitive information
* Appropriate handling of children's personal data
* GDPR-conscious system design
