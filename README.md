Simply Rugby

A full-stack, database-driven rugby club management system developed using PHP OOP, MVC architecture, MySQL and custom routing. The system features authentication and role-based access control for administrators, coaches, players and parents. Security controls were implemented to prevent unauthorised access to protected pages, data and functionality, including direct URL access attempts.

The application includes dedicated parent and player dashboards, player reports, training scheduling, injury management and match management, supported by a structured relational database.

Overview

Simply Rugby is a database-driven web application developed using PHP Object-Oriented Programming (OOP) and MVC (Model-View-Controller) architecture. The system uses a structured routing system to direct requests to the appropriate controllers and enforce access to protected functionality.

Different functionality and permissions are provided for administrators, coaches, players and parents, allowing rugby clubs to manage day-to-day operations through a centralised platform.

Project Structure

The application follows an MVC-based architecture to separate application responsibilities:

* Models – Handle database interaction and data-related operations
* Views – Handle the presentation and user interface
* Controllers – Process requests, apply application logic and coordinate models and views
* Routing – Direct incoming requests to the appropriate controller and action
* Authentication & Authorisation – Control access to protected routes and functionality

This structure improves separation of concerns, maintainability and scalability while making the application easier to extend.
